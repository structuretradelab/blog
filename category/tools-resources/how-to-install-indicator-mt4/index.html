You've downloaded a custom indicator. You're excited to try it. But how do you actually get it onto your MT4 chart?

💡 Key Takeaway: Custom indicators go in the MQL4 → Indicators folder inside your MT4 Data Folder. Copy the file there, refresh the Navigator, and the indicator appears.

Understanding Indicator File Types

Before you install, you need to know what you're dealing with. MT4 custom indicators come in two file types:

File Type What It Is What to Do
.ex4 Compiled indicator file Copy directly to the Indicators folder — it works immediately
.mq4 Source code file Must be compiled in MetaEditor first before it can be used

Most indicators you download will be .ex4 files. If you get a .mq4 file, you'll need to compile it (see the troubleshooting section).

⚠️ Important: If the download is a ZIP file, extract it first. You need the actual .ex4 or .mq4 file, not the ZIP.

Step-by-Step Installation (Windows)

Here's the exact process for installing an indicator on MT4 for Windows:

Step 1: Download the Indicator

Download your indicator from a trusted source. Save it to your Desktop or Downloads folder so it's easy to find.

Step 2: Open the MT4 Data Folder

  1. Open MetaTrader 4
  2. Click File in the top-left menu bar
  3. Select Open Data Folder

A Windows File Explorer window will open. This is where MT4 stores all your local data — not the Program Files folder where the platform is installed.

Step 3: Navigate to the Indicators Folder

Inside the Data Folder, open these folders in order:

  1. MQL4
  2. Indicators

The full path is: Data Folder → MQL4 → Indicators

Step 4: Copy the Indicator File

Copy (or drag and drop) your .ex4 or .mq4 file into the Indicators folder.

Close the folder window when done.

Step 5: Refresh the Navigator

  1. Return to MT4
  2. Open the Navigator panel (press Ctrl + N if it's not visible)
  3. Right-click anywhere inside the Navigator
  4. Click Refresh

Your indicator should now appear under the Indicators section in the Navigator list.

📌 Pro Tip: You don't need to restart MT4. The Refresh option is faster. But if the indicator still doesn't appear, restarting the platform will work.

Installation on Mac

MT4 on Mac runs through a Windows compatibility layer (Wine). The file manager looks different, but the process is similar:

  1. Open MT4 and go to File → Open Data Folder
  2. In the window that opens, look at the left sidebar for a disk icon (often labeled Z: or a disk image)
  3. Click it, then navigate to Users → [YourMacUsername]
  4. Find your indicator file (in Downloads or Desktop)
  5. Right-click the file and select Copy
  6. Navigate back to the Data Folder
  7. Open MQL4 → Indicators
  8. Right-click in the folder and select Paste
  9. Refresh the Navigator in MT4
⚠️ Mac Note: You cannot drag and drop files directly from Mac Finder into the MT4 window. You must use the internal file explorer method above.

How to Apply the Indicator to a Chart

Once the indicator is in the Navigator, here's how to put it on a chart:

  1. Open the chart you want to analyze
  2. In the Navigator, find your indicator under the Indicators section
  3. Double-click it, or drag and drop it onto the chart
  4. A settings window will appear with these tabs:
    • Common: DLL imports and display settings
    • Inputs: Adjust the indicator parameters
    • Colors: Change line colors and styles
    • Levels: Add horizontal lines (for oscillators)
    • Visualization: Limit which timeframes show the indicator
  5. Adjust the settings as needed
  6. Click OK

The indicator will now appear on your chart.

📌 Pro Tip: Some indicators draw in a separate window below the chart (like RSI or MACD). Others draw directly on the price chart (like Moving Averages). This depends on how the developer built it.

Troubleshooting: Indicator Not Showing Up

If your indicator doesn't appear in the Navigator after installation, check these common issues:

Problem Solution
File is .mq4, not .ex4 You need to compile it. Open MetaEditor (F4 in MT4), open the .mq4 file, and click Compile. This creates the .ex4 file.
Indicator is in the wrong folder Make sure it's in MQL4 → Indicators, not in a subfolder unless the developer specified one.
Navigator not refreshed Right-click in the Navigator and click Refresh. Or restart MT4.
Indicator is for MT5 MT4 and MT5 use different file formats. An MT5 indicator (.ex5) won't work on MT4. You need the MT4 version.
Compilation errors If you compiled an .mq4 file and got errors, the indicator won't load. Check the MetaEditor error log.
⚠️ The Most Common Issue: Downloading an MT5 indicator by mistake. Always check that the file is for MT4 before downloading.

Safety: Download from Trusted Sources

Not all indicators are safe. Some contain malicious code or are designed to steal your data.

Safe sources:

  • MQL5 Market: The official MetaTrader marketplace. Files are scanned.
  • ForexFactory forums: Community-developed indicators, usually open source.
  • GitHub: Developers sharing code publicly.

Red flags:

  • Files ending in .exe — a real indicator is always .ex4 or .mq4
  • Websites asking for your MT4 login credentials
  • "Guaranteed profit" indicators with no track record
📌 My Rule: I only download indicators from the MQL5 Market or well-known community forums. I never download .exe files claiming to be indicators. And I always test on a demo account first.

Install Once, Use Forever

Installing an indicator on MT4 is a one-time process. Once it's in the Indicators folder, it stays there until you remove it.

Download from a trusted source. Copy to MQL4 → Indicators. Refresh the Navigator. Apply to your chart. That's how your indicators are ready in under a minute.
