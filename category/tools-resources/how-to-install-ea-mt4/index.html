You've downloaded an Expert Advisor (EA). You're ready to let a robot trade for you. But first, you need to install it.

Installing an EA is similar to installing an indicator, but there are a few extra steps — and one critical setting that most beginners forget. If you miss it, the EA will load, but it won't trade.

In this guide, let's walk through the process of installing, attaching, and enabling an EA on MT4.

💡 Key Takeaway: EAs go in the MQL4 → Experts folder. After attaching to a chart, you must enable AutoTrading on the toolbar AND check "Allow live trading" in the EA settings. Both are required.

Before You Start: Safety First

EAs can execute trades automatically. If something goes wrong, you could lose money fast. Before you install any EA:

  • Test it on a demo account first. Never run an untested EA on a live account.
  • Download from trusted sources. The MQL5 Market is the official, safest option.
  • Understand what the EA does. Read the description. Know its strategy, risk settings, and recommended timeframe.
⚠️ Important: EAs run only while MT4 is open and connected. If your computer sleeps or loses internet, the EA stops. For 24/7 operation, you need a VPS.

Step-by-Step Installation (Windows)

Here's how to install an EA on MT4:

Step 1: Download the EA

Download your EA file. It will be either a .ex4 (compiled) or .mq4 (source code) file.

Step 2: Open the MT4 Data Folder

  1. Open MetaTrader 4
  2. Click File → Open Data Folder

Step 3: Navigate to the Experts Folder

Inside the Data Folder, open: MQL4 → Experts

This is where MT4 looks for Expert Advisors.

Step 4: Copy the EA File

Copy or drag your .ex4 or .mq4 file into the Experts folder.

Step 5: Refresh the Navigator

  1. Return to MT4
  2. Open the Navigator (Ctrl + N)
  3. Right-click on Expert Advisors and select Refresh

The EA should now appear under the Expert Advisors section.

📌 Pro Tip: If the EA doesn't appear, close and reopen MT4. The platform reloads the MQL4 folders on startup.

How to Attach the EA to a Chart

Once the EA is in the Navigator, here's how to put it on a chart:

  1. Open the chart for the instrument you want the EA to trade
  2. Make sure the timeframe matches what the EA was designed for
  3. Drag the EA from the Navigator onto the chart, or double-click it
  4. The EA settings window opens

The Settings Window

You'll see several tabs:

  • Common: Permissions (Allow live trading, Allow DLL imports)
  • Inputs: The EA's parameters (lot size, risk, stop loss, etc.)

Critical step: On the Common tab, check "Allow live trading". Without this, the EA will load but won't place trades.

Click OK to attach the EA.

Enabling AutoTrading (The Critical Step)

This is where most beginners get stuck. MT4 has two switches that must both be on for an EA to trade:

Switch Where to Find It What It Does
Global AutoTrading Toolbar button (top of MT4) Enables automated trading for the entire terminal. Must be green (play icon).
Per-EA Permission "Allow live trading" checkbox in EA settings Allows this specific EA to trade.

How to enable global AutoTrading:

  • Look for the AutoTrading button on the toolbar
  • If it shows a red stop icon, click it to turn it green

Also check: Go to Tools → Options → Expert Advisors and ensure "Allow automated trading" is checked.

⚠️ The #1 Reason EAs Don't Trade: Either the global AutoTrading button is off, or "Allow live trading" wasn't checked. Both must be on.

How to Verify the EA is Running

After attaching the EA and enabling AutoTrading, check the top-right corner of your chart:

Icon What It Means
😊 Smiley Face EA is active and trading is enabled. Everything is working.
☹️ Frown / "X" EA is loaded but not trading. AutoTrading is off, or "Allow live trading" is unchecked.
L Live trading is disabled in the EA settings.

If you see a smiley face, your EA is ready. If not, double-check both switches from the previous section.

Troubleshooting: EA Not Trading

If your EA shows a smiley face but still isn't placing trades, check these common issues:

Problem Solution
DLL imports needed If the EA requires .dll files, go to Tools → Options → Expert Advisors and check "Allow DLL imports".
Symbol name mismatch Your broker's symbol might have a suffix (e.g., EURUSD.m instead of EURUSD). Check the EA's input settings or the EA code.
Insufficient margin Check your account balance. The EA might be trying to open a position larger than your free margin allows.
Market closed If the market is closed (weekend), the EA won't trade. Wait for market open.
Check the logs Go to the Terminal window → Experts tab. Any errors the EA encounters will be logged there.
📌 Pro Tip: Always check the Experts log after installing an EA. It will tell you exactly why the EA isn't trading — permission issues, invalid stops, or connection problems.

Install, Attach, Enable — In That Order

Installing an EA is not complicated, but it requires attention to detail. The most common mistake is forgetting the global AutoTrading button. Once you've done it a few times, it becomes second nature.

Copy the file to MQL4 → Experts. Attach it to a chart. Check 'Allow live trading.' Turn on the global AutoTrading button. Verify the smiley face. That's how your EA is ready to run.
